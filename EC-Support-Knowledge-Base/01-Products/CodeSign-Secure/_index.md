# CodeSign Secure

CodeSign Secure is the Encryption Consulting (EC) platform for signing software, packages, and container images with keys that never leave a Hardware Security Module (HSM). This section covers setup, daily signing tasks, policies, and troubleshooting. New administrators should start with the overview and the prerequisites article.
