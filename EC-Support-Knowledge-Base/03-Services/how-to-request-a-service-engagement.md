# How to Request a Service Engagement

This article explains how to request an advisory, assessment, implementation, or managed support engagement from Encryption Consulting (EC). It lists what to prepare, what happens at each step, and how a request becomes a scheduled project. It is for security leaders, project managers, and procurement contacts.

## Overview

A service engagement is project work done by EC consultants, such as a Public Key Infrastructure (PKI) assessment or a Hardware Security Module (HSM) deployment. It is different from a support case. Use a support case for problems with an EC product or a service already under contract. See [How to open a support case](../00-Working-with-EC-Support/how-to-open-a-support-case.md).

The request flow:

1. Prepare basic scope information.
2. Contact EC.
3. Join a scoping call.
4. Review the proposal and Statement of Work (SOW).
5. Sign and schedule.
6. Kickoff.

## Prerequisites

- A business owner or sponsor who supports the request.
- A rough idea of the problem to solve or the outcome needed.
- Authority, or a path to authority, to sign a contract.

## Before starting

Collect the following details. Rough estimates are fine at this stage.

| Item | Examples |
|---|---|
| Business driver | Upcoming audit, outage, new regulation, migration, post-quantum cryptography (PQC) planning |
| Service of interest | One or more services from the list above |
| Environment size | Number of Certificate Authorities (CAs), HSMs, cloud accounts, applications, or sites |
| Platforms | For example Microsoft Active Directory Certificate Services (AD CS), Thales Luna, Entrust nShield, AWS, Azure, Google Cloud |
| Frameworks | For example Payment Card Industry Data Security Standard (PCI DSS) v4.0.1, NIST Special Publication (SP) 800-57, Federal Information Processing Standard (FIPS) 140-3, Digital Operational Resilience Act (DORA), or the Network and Information Security Directive (NIS2) |
| Target dates | Audit dates, change freezes, or deadlines |
| Constraints | On-site needs, security clearance, data residency, working hours |

> **Note:** Do not include secrets, private keys, passwords, or detailed vulnerability data in the first request. EC sets up a secure exchange channel once the engagement starts. See [Secure file sharing with EC support](../00-Working-with-EC-Support/secure-file-sharing-with-ec-support.md).

## Procedure

### Phase 1: Contact EC

1. Submit a request through {{TBD: services request form URL or portal menu}}, or email {{TBD: services or sales email address}}.
2. Include the details from the table above.
3. Existing customers can also ask their account manager: {{TBD: account management contact}}.

### Phase 2: Scoping call

1. EC schedules a scoping call within {{TBD: target time to schedule a scoping call}}.
2. On the call, EC and the customer confirm goals, scope, stakeholders, and constraints.
3. If needed, the parties sign a Non-Disclosure Agreement (NDA) before sharing detailed architecture: {{TBD: confirm NDA process}}.

### Phase 3: Proposal and SOW

1. EC sends a proposal and SOW that lists scope, phases, deliverables, assumptions, and customer responsibilities.
2. Review the SOW with technical, security, and procurement teams.
3. Ask EC to adjust scope or phases if needed.

### Phase 4: Sign and schedule

1. Sign the SOW and issue a purchase order if required by internal process.
2. EC assigns a project lead and confirms start dates.

### Phase 5: Kickoff

1. Attend the kickoff meeting with the named stakeholders.
2. Confirm the project plan, communication plan, and status meeting schedule.
3. Start the document and access requests listed in the service guide for the chosen service.

## Verification

The request is complete when:

- A signed SOW exists.
- A named EC project lead and a named customer project lead are confirmed.
- A kickoff date is on the calendar.

## Troubleshooting

| Symptom | Likely cause | Resolution |
|---|---|---|
| No reply after submitting a request | Request went to the wrong channel or a spam filter | Resend to {{TBD: services or sales email address}} or contact the account manager |
| Scope keeps growing during scoping | Goals not agreed internally | Agree on the top goal first. Start with an assessment and add phases later. |
| Engagement start is delayed | Missing approvals, access, or stakeholders | Confirm sponsors, interviewees, and access before kickoff |
| Problem with a live system needs urgent help | A support case is needed, not a new engagement | Open a support case. See [How to open a support case](../00-Working-with-EC-Support/how-to-open-a-support-case.md). |
