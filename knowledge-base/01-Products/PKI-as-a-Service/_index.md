# PKI-as-a-Service

Encryption Consulting (EC) PKI-as-a-Service (PKIaaS) is a fully managed private Public Key Infrastructure (PKI) with HSM-backed root and issuing Certificate Authorities (CAs). The articles below explain how the service works, who does what, and how to onboard and enroll certificates. Start with the overview, then read the shared responsibility article before onboarding.
