# HSM-as-a-Service

Encryption Consulting (EC) HSM-as-a-Service (HSMaaS) provides managed, FIPS 140-3 validated Hardware Security Modules (HSMs) in the cloud, on-premises, or both. The articles below cover what the service includes, who does what, how to connect applications, and how keys stay available and recoverable. Start with the overview, then follow the onboarding guide.
